# Change Log

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-21

### Added
- Initial release
- CPF/CNPJ + password authentication
- Multi-installation support
- Electricity consumption sensors (daily, monthly, yearly)
- Billing sensors (current bill, due date, reference month)
- Account balance sensor
- Consumption and billing history as sensor attributes
- Portuguese (pt-BR) and English (en) translations
- HACS validation and Hassfest CI workflows
